🌐 Responsive Grid Layout - Flutter

This Flutter project displays a list of countries using responsive cards. The layout automatically adjusts based on the screen size:

- 📱 Mobile: 2 cards per row
- 📲 Tablet: 3 cards per row
- 💻 Desktop/Web: 4 cards per row

🚀 Features

- Fully responsive UI
- Dynamic layout using `GridView.builder`
- Clean and minimal design
- Flutter-based card components

✨ Features

Responsive UI powered by flutter_screenutil to ensure consistent scaling across devices.

Adaptive Grid Layout that intelligently adjusts based on screen size (mobile, tablet, or desktop).

Beautiful Card Design displaying country flags, ratings, enrollment numbers, and interactive action buttons.

Supports Multiple Countries including Bangladesh, France, Germany, Australia, Spain, USA, Italy, and Japan.
